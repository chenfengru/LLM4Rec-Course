# Week 01 — Introduction to Recommender Systems

## Core concepts

- Recommender systems aim to provide personalized recommendations based on user preferences.
- Introductory recommendation approaches:
  - Content-Based Filtering
  - Collaborative Filtering
- Machine-learning recap:
  - supervised learning
  - classification
  - regression
  - unsupervised learning
  - clustering
  - dimensionality reduction
- Recommendation evaluation includes:
  - Precision@K
  - Recall@K
  - MAP@K
  - Hit Rate@K
  - NDCG@K
  - MRR
  - RMSE / MAE
  - Diversity / Coverage
