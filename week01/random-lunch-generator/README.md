# Week 01 — Random Lunch Generator

## Goal

Build a simple web application that recommends a random lunch option.

This is intentionally a **random baseline**, not yet a personalized recommender.

## Required behavior

1. User clicks **Generate Lunch!**
2. JavaScript selects one menu item using `Math.random()`.
3. The selected lunch is displayed to the user.
